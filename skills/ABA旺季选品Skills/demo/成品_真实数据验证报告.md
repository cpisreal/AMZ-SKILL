## 四、分析 → 决策：最后一公里

| 指标 | 对应动作 |
|---|---|
| 加速峰（起量时间） | 加速峰前 1–2 周完成上架，加速峰当周广告开跑 |
| 加速值（起量速度） | 急涨型猛推；慢热型养节奏、拉长投放窗 |
| 12 周词条总量（量级） | 决定投入资源量级：量级大才值得压库存 |
| 节奏形态 | 决定备货深度：脉冲型小批量多款，缓降型可深备 |
| 尾周占比 | 决定库存风险：尾周高 → 节后还能收；尾周低 → 必须提前清 |
| 半衰期 | 决定清货节奏：半衰期 1 周 = 清货窗口极短 |

## 五、形态 → 备货策略

| 形态 | 备货/广告动作 |
|---|---|
| 早峰缓降型 | 可以多备，节后还能收；广告提前 2 周铺　**适用**：家居布艺、户外充气装饰 |
| 晚峰热尾型 | 热尾型：可多备，节后仍有量；广告延续到节后　**适用**：圣诞树、灯饰、挂饰、装饰（泛）、贺卡、包装纸袋、玩具游戏 |
| 晚峰脉冲型 | 脉冲型：小批量多款，绝不深备　**适用**：圣诞礼物（泛）、睡衣、礼物盒袋 |
| 晚峰缓降型 | 常规备货；广告跟随词量曲线　**适用**：服装、毛衣、圣诞袜、餐桌用品、花环藤蔓、食品、礼盒套装、袜子／围巾配件 |
