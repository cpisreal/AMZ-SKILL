# ABA 同质度打分 · 判断一个词能不能带自然单

> **对外名称**：这个 skill 交付给读者时叫 **Codex Skill**（公众号文章标题写
> 「Codex Skill：投前判断一个词能不能带自然单」，文末回复关键词「自然单」领取）。
> 内部名仍是 `lingfei-aba-standard-vs-nonstandard`，两者指同一件东西。

## 〇 什么时候用这个 skill

用户提出下面任何一类问题时：

- 「这个词如果我把广告投起来、排名做上去，能不能带来更多自然单？」
- 「标品和非标品在 ABA 里的点击/转化份额有什么本质区别？」
- 「ABA 里前三名的点击份额能不能用来判断值不值得抢？」
- 「为什么排名上去了、自然单没涨？」
- 需要为一个关键词清单排出「抢排名 / 只买订单 / 不值得投」三档优先级。

**不适用**：判断一个词有没有需求（那是搜索量/排名的事）、判断转化率高低（那是自家 listing 的事）、
判断类目大盘趋势（那是 GMS/季节性的事）。

## 一 核心判断（全文只服务这一句）

> **决定一个词能不能带自然单的，不是"标品/非标品"这个标签，而是它的前三个产品有没有
> 同时吃掉点击和转化：点击垄断告诉你「图片像不像」，转化垄断才告诉你「买家认不认这一个」。**

一句话推论：**两个维度会背离。点击集中但转化不集中 = 陷阱区**——广告能把排名推上去、
自然单不跟。这是本 skill 存在的最主要理由。

## 二 口径：三层标准化（不做这三层，结论必错）

### 第一层：份额怎么算

`top3_click = Click Share #1 + #2 + #3`，`top3_conv = Conversion Share #1 + #2 + #3`。
只用官方原始报告里的这 6 列；二次加工过的窄表常常丢掉转化份额那三列。

### 第二层：必须按排名分层

按 `Search Frequency Rank` 切 6 层：`<1k / 1k-5k / 5k-20k / 20k-100k / 100k-500k / >500k`，
**每层各自算该周全量词的中位数**。

实测（2026-09-12 周，271.8 万词）各层点击份额中位：**29.0 / 30.1 / 31.5 / 32.4 / 33.9 / 39.0**。

> 🔴 **不要用全量中位数当基线**：全量中位是 **38.1%**，因为长尾词（>50 万名的有 221 万个）
> 天然接近 100%，会把基线整体抬高，导致大量正常词被误判成「低集中」。

### 第三层：两个比值

```
rel_click = top3_click ÷ 该层点击份额中位     1.0 = 与大盘持平
rel_conv  = top3_conv  ÷ 该层转化份额中位
head_share_click = top3_click ÷ 3            进前三后平均能分到的点击份额（份额天花板）
```

**为什么必须同层**：同层比较才能排除「搜索量大小」这个混淆变量。实测排除后结论不变
（标品每层 ±10~30% 贴着大盘，非标品每层只有大盘 4–6 成），说明差异不是搜索量造成的。

## 三 分档与动作表

分档看 **rel_conv**（区分度 AUC 0.948，是 rel_click 的 0.855 之上最强的一个；搜索排名只有 0.647）。

| 档位 | rel_conv | 含义 | 动作 |
|---|---|---|---|
| **A** | ≥1.5 | 转化强垄断 | 抢前三，回报明确（愿意为排名付溢价） |
| **B** | 0.8–1.5 | 跟得上大盘 | 可打，但按 ACoS 控 |
| **C** | 0.3–0.8 | 转化偏散 | 只买直接订单 |
| **D** | <0.3 | 转化不归头部 | 只买直接订单，**不为自然位溢价** |

四象限（横轴 rel_click、纵轴 rel_conv）与动作：

| 象限 | 判据 | 动作 |
|---|---|---|
| 赢家通吃 | 点击高 · 转化高 | 抢前三 |
| 精准需求 | 点击低 · 转化高 | 排名价值最高，优先做长尾卡位 |
| **陷阱区** | 点击高 · 转化低 | **降预算，别当自然位投资** |
| 纯碎片 | 两头都低 | 广告当直接订单买 |

## 四 脚本用法

依赖：`duckdb`（本机在独立环境 `~/Desktop/ABA关键词工具/.venv`，不要装进系统 Python）。

```bash
# 打分指定词表（一行一个词）
python3 scripts/aba_homogeneity_score.py \
  --aba "/Volumes/UD800/01_ABA数据/US_Top_Search_Terms_Simple_Week_2026_09_12.csv" \
  --terms terms.txt --out scored.csv

# 或打分该周排名前 2000 的词（建立自己的分档清单）
python3 scripts/aba_homogeneity_score.py --aba <周报CSV> --top 2000 --out top2000.csv
```

输出列：`term / rank / layer / top3_click / top3_conv / rel_click / rel_conv /
head_share_click / head_share_conv / band / quadrant / action`。

脚本会先打印六层的基线，**先核基线对不对再看词**——基线不对说明文件读错了（多半是 `skip=1` 或列名）。

## 五 五条必踩的坑

1. **用绝对值判断集中度** → 长尾污染。必须先分层、再除基线。
2. **把 `rank` 当名次** → 长尾的 rank 是桶号（大量词共享同值），只能用来分层，不能做趋势/极值。
3. **只看点击不看转化** → 最大的坑。内衣类目实测：点击 24.7%（正常）、转化 0.7%（只有大盘 0.04 倍）。
4. **样本太小/单周下结论** → 非标品点击份额四周在 10.6%–18.5% 之间摆，单周可能刚好读到最高值。
5. **拿"标品/非标品"当判据** → 标签只是先验。标品里 `brake pads` 的 rel_conv 只有 0.13（D 档），
   而非标品里最高的 `shower curtain` 是 0.95（B 档）——标签保证不了档位。

## 六 证据强度与边界（引用时必须带上）

**已证实（可直接当事实说）**：500 个观测（标品 240 + 非标品 260，四周）、控过排名层——
- 非标品前三转化份额 = 同层大盘的 **0.277 倍**（标品 1.469 倍），AUC **0.948**
- A 档（rel_conv ≥1.5）**114 个观测全部是标品，非标品 0 个**
- 「前三吃三成点击」是 6 个排名层的共同常态（29%–39%）

**方向性（有逻辑支撑、未实测）**：
- 转化垄断度高的词，排名提升后自然单占比更高 —— 这是本模型的业务假设，
  ABA 里**没有自然单数据**，需要用自家后台做前后对照才能证实

**未验证（本机数据不足）**：
- 广告 ACoS 是否随档位单调变化 —— 实盘样本里 A 档只有 0 个词，没有对照
- 自然订单的实际增量 —— 需要同一批词做「上排名前后」配对比较

**口径局限**：125 个词是按品类常识人工挑的先验样本，AUC 衡量的是「在这个样本上能不能分开」，
不是「全体 271 万词的真实分布」；要拿全量分布，必须对所有词跑一遍脚本。

## 八 复用到别的类目

只需要换两组词（标品 N 个 + 非标品 M 个），其余不动：
分层 → 除基线 → 定档。**基线必须用你自己那份周报的全量词重算**，不能套本文的数字。

如果连两组词都不想挑：直接 `--top 2000` 跑全量前列，按下表看分布，
你自己类目的「档位基线」就出来了（各档占比），之后拿单个词的档位跟这个分布比。
