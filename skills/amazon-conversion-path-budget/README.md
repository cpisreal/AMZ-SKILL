# 转化路径报告 · 预算分配分析

一份把亚马逊「转化路径报告」读成「预算该怎么分」的小工具。

不需要 API、不需要授权、不上传任何数据。你把后台导出的报表喂给它，它输出一份结构分析 + 几句能直接用的判断。

## 它回答什么问题

- 我的钱压在几条路径上？
- 哪个广告在开场，哪个只在助攻？
- 商品推广跑起来之后，下一笔预算该给谁？
- 品牌推广、展示型推广、DSP 各自到底占多少份量？
- 路径越长越值钱吗？

## 安装

只需要 Python 3.8+，加一个读 Excel 的库：

```bash
pip install openpyxl
```

（如果你的报表导出成 CSV，连这个都不用装。）

## 用

**第一步：导报表。**
广告后台 → 报表中心 → 报表类型选 **Conversion path** → 时间范围 **30 天** → 下载 xlsx 或 csv。

**第二步：跑。**

```bash
python scripts/analyze_conversion_path.py 你的报表.xlsx
```

想同时导出 Excel 汇总：

```bash
python scripts/analyze_conversion_path.py 你的报表.xlsx --out 分析结果.xlsx
```

导出的 Excel 有 7 个表：概览、首触点、转移关系、触点分层、产品覆盖、单点路径、判断与动作。

**第三步：看第六块「判断与动作」。**
前面五块是指标，第六块把它翻成了话。每条判断都配一个动作，直接能用。

## 输出长什么样

```
路径 298 条 | 销售 $5,239,589 USD | 订单 125,451 | 客单价 41.8 | 新客占比 71.9%

【一】集中度：钱压在几条路径上
  第 1 条 41.3% | 前 2 条 62.5% | 前 4 条 83.3%
  累计到 50% 需 2 条，到 80% 需 4 条
  长尾（单条 < 0.05%）253 条，合计 1.5%

【三】A 跑了之后接什么（首→次转移）
  A        → B          路径          销售      占比     客单价
  SP       DSP          20  $1,226,524   23.4%    43.3
  ...

【六】判断与动作
  !! 结构高度集中：前 2 条路径占 62.5%……
     → 主力按护栏管理，增量放到新位置，不动存量。
  !  DSP 是助攻型：出现在 75.5% 的路径里，自己开场只占 23.2%……
     → 按覆盖考核，不用末次点击 ROI 判去留。
```

完整样例见 `examples/sample_output.md`。

## 重要提醒

这是**路径归因**，不是因果。某个广告出现在成交路径里，只说明买家被它触达过，不说明它促成了这单。要证明因果只有关停实验一条路。

所以这份分析的用法是：**排除明显错误的判断**（比如「DSP 完全没参与」「这个广告可以无脑砍」），而不是**证明谁有效**。

## 判定阈值

脚本顶部有一个 `TH` 字典，四五个数字控制所有判断的门槛：

```python
TH = {
    "concentrated_top2": 0.60,      # 前 2 条占比超过 → 结构高度集中
    "assist_gap": 0.15,             # 覆盖率 − 开场率 超过 → 助攻型
    "companion_ratio": 5.0,         # 覆盖/销售 比值超过 → 伴随型
    "long_chain_gap": 0.05,         # 长链路新客低于整体这么多 → 偏收割
    "main_transfer": 0.10,          # A→B 占总额超过 → 主要转移关系
    ...
}
```

这些是经验值，不是平台标准。你的账号结构不一样就改它。
