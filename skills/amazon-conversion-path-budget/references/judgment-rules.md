# 判定规则：依据、阈值、反例

脚本里每条判断都有一条规则。这里写清它们怎么来的、什么时候会判错。

所有阈值在脚本顶部 `TH`：

```python
TH = {
    "concentrated_top2": 0.60,
    "assist_gap": 0.15,
    "companion_ratio": 5.0,
    "long_chain_gap": 0.05,
    "main_transfer": 0.10,
    "longtail_each": 0.0005,
    "assist_min_share": 0.10,
}
```

## 一 · 结构高度集中：前 2 条 ≥ 60%

**依据**：转化路径几乎必然是幂律分布。广告产品就那么几种，能形成稳定组合的更少，所以「SP 单点」「SP→DSP」「DSP 单点」「DSP→SP」这四种就能覆盖大部分成交。

**为什么 60%**：前两条占到六成，意味着任何对这两条的改动都会直接反映到总销售。这是「不能拿它当实验对象」的信号。

**动作**：主力广告按护栏管理。要动就动增量，不动存量。

**反例**：新账号、刚铺开多产品线的账号，路径分布会很散（前 2 条可能只有 30%）。这时候不该判「分散风险做得好」，而该先问「是不是还没有一条路径跑出来」。

## 二 · 单触点路径 ≥ 15%

**依据**：只经过一个广告就成交的路径，代表「搜到就买」的人群，决策快、没什么可比。这类路径占比高，说明搜索流量质量好，也说明你的增长暂时不依赖上层广告。

**为什么单列**：它是全表里最不能动的一块。很多人优化时会先挑「占比最大的那条」下手，恰恰是最危险的动作。

**动作**：任何改动（出价、关键词、素材）先小流量验证。

**反例**：如果是品牌词贡献了这条单点路径，那它更接近「吃品牌存量」，这时候要查新客占比。新客占比也高的，才是真·搜索转化好。

## 三 · 助攻型：销售占比 ≥ 10% 且「覆盖率 − 开场占比」≥ 15pt

**依据**：这类广告有份量（参与路径的销售合计不低），但自己开来单的能力弱（很少是第一个触点）。说明它的价值在「中间补频次」，不在「直接获客」。

**为什么加销售占比 ≥ 10% 的门槛**：不加这条，几乎所有非主力广告都会被判成助攻型，输出变成噪音。10% 是「值得单独管理」的量级线。

**动作**：按覆盖考核，不用末次点击 ROI 判去留。那个数字永远难看，因为最后一步基本都是商品推广。

**反例**：如果一个广告覆盖率高、开场率低，但**销售占比也很低**（< 10%），那不是助攻型，是伴随型，见下条。

## 四 · 伴随型：销售占比 < 10% 且覆盖率 ≥ 15%

**依据**：出现率高、销售占比低 —— 说明它几乎出现在每条路径上，但它在的那条路径单子都不大。角色是「人快决定了的时候补一刀」，不是「把人拉进来」。

用「覆盖/销售」比值看更直观：比值 37 倍的广告，覆盖 35% 的路径却只带来 0.9% 的销售。

**动作**：按维持给预算。砍掉会让最后一步少一层确定性，加钱也放不出量。

**反例**：如果一个账户的 SBV 客单价明显高于其他产品（比如高 8 美元），即便销售占比低，也值得微增 —— 它的问题不是转化质量，是覆盖量。脚本的判断不带这层，需要自己看客单价那一列。

## 五 · 长链路偏收割：3+ 触点新客占比 < 整体 − 5pt

**依据**：触点数量本质是「这个买家的决策周期有多长」。一个触点就买的人没什么可比较，新客比例天然高；走过四五个触点的人在被反复触达、反复比价，这类人往往是老客在等价格或等新款。

**经验规律**：客单价随触点增加而上升，新客占比同时下降。两条曲线方向相反。

**动作**：拉新预算给 1–2 触点的短路径；长链路按复购指标考核，别挂在拉新目标上。

**反例**：高客单大件（200 美元以上）本来就该走长链路，新客占比低是正常的。这类品类不要硬压短链路。

## 六 · 主要转移：A→B 占总额 ≥ 10%

**依据**：首接触点 A、第二触点 B 的组合占到总额 10% 以上，说明这是一条被反复验证的接力关系。

**动作**：A 跑稳之后，增量预算优先给 B。

**反例**：注意区分「路径」和「转移」。`SP > DSP > [Purchase]` 是一条两触点路径；而「SP→DSP 转移」还包括 `SP > DSP > 某产品 > [Purchase]` 这类三触点路径。所以转移的占比会**大于**单条两触点路径的占比。看到数字对不上不是 bug。

## 没被规则覆盖的情况

**跨字段一致性**：报表不提供「这个路径是否合理」的校验。别自己脑补。

**因果**：所有规则都只处理「出现在路径里」，不处理「促成了成交」。要因果只能做关停实验。

**预算百分比**：脚本刻意不给「SP 该占 40%」这种数。报表能给你分配**结构**（谁基本盘、谁助攻、谁伴随），给不了**比例**，比例要结合你自己的 ACoS、库存和毛利定。
