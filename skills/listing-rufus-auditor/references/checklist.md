# Listing AI-Readiness Checklist

## Minimum viable AI-ready listing
- Title states product type, primary use case, key spec, compatibility, and count/model.
- First bullet explains the main buyer problem and exact product solution.
- Every major claim appears in at least one retrievable evidence source.
- Attributes include material, dimensions, compatibility, color/size, count, model number, and package contents where relevant.
- Q&A covers fit, compatibility, installation/use, sizing, what's included, and comparison with alternatives.
- Images show dimensions, use case, package contents, and compatibility or comparison chart.
- A+ modules are structured as standalone answers, not only brand storytelling.
- Variations are clean and differences are explicit.
- Inventory is stable for promoted or launch ASINs.

## Common red flags
- Vague claims: high quality, premium, best, durable, easy, perfect.
- Specs appear in images only but not text/attributes.
- Important compatibility data appears only in reviews.
- First bullet repeats the title instead of adding evidence.
- Different units or terms for the same spec across title, bullets, and images.
- Parent-child variations combine unrelated products.
- Q&A is empty or contains contradictory answers.
- A+ content is beautiful but not answerable.
