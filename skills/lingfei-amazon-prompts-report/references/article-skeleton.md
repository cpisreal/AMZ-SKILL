# 文章骨架：每一节放什么数字

这是被验证过的结构（一篇八千字上下、十几张图的成稿，读者反馈"终于看懂了"）。
**先给方法，再给结论** —— 结论后置是这一篇的骨架决定，不是巧合。

---

## 开篇（不进小标题）

1. **第一句必须是具体事实或具体结果**，不是行业感慨。
   样例：`有一条提问，被推了 2 次，2 次都被点开，成交 〈N〉 美元。`
2. **第二句形成反差**：另一条被推了几万次、花十几美元、换回的钱和第一条差不多。
3. **第三句点破读者的默认动作**：拿到表先排 ACOS，排完只看见第二条，第一条永远沉在最后几页。
4. **一段话交代全文承诺**：这张表是什么、有什么区别、五把刀各解决什么、每把刀取什么列怎么算、
   最后拿一份真实报表走一遍。
5. **样本交代**：ASIN 数、活动数、行数、提问数、曝光、花费、销售、整体 ACOS。
6. **脱敏声明**：`为保护客户信息，下文出现的具体品类一律写作〔品类〕/ [CATEGORY]。`

## 第一节 先讲清这张表是什么

给"从没打开过它"的人看。小标题：它记的是买家对着 AI 说的那句话 / 这句话是怎么被挑中的 /
它不是一种新的广告类型 / 二十四列真正要算的只有八个 / 拿一行数据我带你读一遍 /
和搜索词报告差在哪 / 十几份报表各自看什么 / 我被问最多的六个问题 /
它能回答什么不能回答什么 / 什么时候该翻它 / 读数字之前先记住三个口径 / 打开是空表怎么办。

必放的读数：
- 报表下载路径五步（Report category / Report type / Country / Time unit / Report period）。
- **只收录「至少被点过 1 次」的提问** —— 这条解释了后面为什么「有销售行占比」会低到个位数。
- 一行真实数据的完整读法（提问原文 + 曝光/点击/花费/销售 + 一句话翻译）。
- 24 列三组（身份 6 / 原话 1 / 流量 4 / 结果 13），真正要算的只有 8 个。
- 与 Search Term Report 的 6 维对照表。
- 六个高频疑问（ACOS 空白、同一句话多行、一个提问多 ASIN、高曝光低点击、数据延迟、只看某个商品）。

## 第二节 先合并，再算比率

- **一行 = 一个提问 × 一个活动 × 一个 ASIN × 一天**（用你自己表里的数字举例：〈提问数〉条提问占了〈总行数〉行）。
- 直接对整张表排序看 ACOS 为什么错（小分母行把排名全污染）。
- 三个必须先知道的坑：只记录跑出过曝光、7 天归因、ACOS/ROAS 是派生列不能取平均。

## 第三–七节 五把刀（每把刀固定四段）

结构固定成：**取什么数据 → 怎么处理（给公式）→ 怎么判读（给分档）→ 这把刀在这份表上的答案**。

| 节 | 必须出现的数字 |
|---|---|
| 第一把刀 体检 | 行数 / 唯一提问 / 唯一 ASIN / 唯一活动 / 有销售行占比 / 整体 ACOS 基准线 |
| 第二把刀 集中度 | 前 10% 与前 50% 的累计花费与销售 / 前十活动占花费比例 / 第一名活动花费 |
| 第三把刀 意图分层 | 六组 × (提问数、曝光占比、花费占比、销售占比、CTR、ACOS) / 覆盖率 |
| 第四把刀 四象限 | 两条线的值 / 四格各多少条 / 低曝光高效那一格占总销售多少 |
| 第五把刀 文本特征 | 五类 × (命中数、曝光占比、CTR、ACOS) / 与全场基准的倍数 |

**第二把刀只能是排除结论时，也要写出来。**
样例："别去翻哪个活动在烧钱，那个方向没有答案。" 排除结论同样是有价值的产出。

## 第八节 补一刀 · 结构

活动 / 时间 / 站点三刀，一屏写完。结论若是"分散"，明说后面不必再区分活动。

## 第九节 五把刀走完，这份表说了什么

把前五节的判决汇总成一张表 + 三到四条判断：

1. 最大错配在哪一格（曝光占比 ÷ 销售占比 最悬殊的组）。
2. 被饿着的是哪一组（销售占比 ÷ 曝光占比 最大、且样本 ≥20 的组）。
3. **极端样本对照表**（4 行长尾赚钱 + 2 行流量黑洞），这一张表比任何形容词都有说服力。
4. **为什么规则反了** —— 回到机制解释（搜索框强迫压缩语言，AI 对话框不强迫）。
5. **必须写一个反例**：找一条推翻你自己字面结论的样本（比如一条很短却特别赚钱的问句），
   用来推翻"话越完整越值钱"的字面理解 —— 真正的变量是**这句话里有没有确定性**。

## 第十节 四个动作

每条动作写成 **条件 + 动作**，并指到具体位置（五点前三条 / A+ 首屏 / 第二张主图 / 适配表）。
结尾加两条执行纪律：改完等 2–3 周；同一批只动一个变量。

## 第十一节 三个边界

单一账户 30 天不是规律 / 只记录跑出过曝光的提问 / 7 天归因。

## 收尾

- 一句把顺序再压一遍的话（"五把刀的顺序不能乱…跳过前两步直接排 ACOS…"）。
- 数据声明一行（脱敏、比例未美化）。
- 一句软钩子（往前翻系列、有问题在群里问），**不写导流链接**。

## 字数与配图

| 项 | 口径 |
|---|---|
| 字数 | 6,000–9,000 汉字（低于 5,000 讲不完五把刀；高于 10,000 要拆两篇） |
| 配图 | 10–16 张，每个大节至少 1 张 |
| 图注 | 每张图注独立可读，不写"如上图所示" |
| 表格 | 6–10 张，六组表 / 四象限表 / 特征表 / 极端样本表是核心 |

## 写之前先问自己一句

**这篇给谁看？** 给"做过亚马逊广告但没打开过这张表"的操盘手看，就从"这一行在说什么"讲起；
给老手看，就从"五个常见误判"讲起。两头都想要，就会两头都不满足。
