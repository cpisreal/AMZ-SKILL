# 成稿结构提要：一篇跑通全流程的文章长什么样

⚠️ **这个包里不含完整成稿，也不含任何真实账户的数字、买家原话或品类。**
完整成稿在飞书文档里，按客户授权单独管理；这里给的是**结构提要 + 反例清单** ——
知道每一节该干什么、该放哪类数字、最容易写坏在哪，就能自己写出一篇。

---

## 全文的骨架（11 节）

开篇 → 这张表是什么 → 先合并再算比率 → 五把刀（五节）→ 补一刀结构 →
五把刀走完说了什么 → 四个动作 → 三个边界 → 收尾。

### 开篇（不进小标题）

| 该写什么 | 用哪类数字 |
|---|---|
| 一句话对比，把"排序 ACOS"这个默认动作打掉 | 一条低曝光高成交 vs 一条高曝光零成交 |
| 一段话交代全文承诺 | 五把刀各解决什么、最后走一遍真实报表 |
| 样本交代 | ASIN / 活动 / 行 / 提问 / 曝光 / 花费 / 销售 / 整体 ACOS |
| 脱敏声明 | 品类、材质、功能一律写 `〔品类〕〔材质〕〔功能〕` |

**写坏的典型**：第一句写"随着 AI 购物的发展……"。第一句必须是一个具体事实或具体结果。

### 第一节 这张表是什么

任务：让从没打开过它的人能读懂一行数据。顺序是
**入口在哪 → 一行怎么读 → 这句话怎么被挑中 → 它不是什么 → 24 列怎么分组 →
和搜索词报告差在哪 → 十几份报表分工 → 六个高频疑问 → 能/不能回答什么 → 什么时候该翻 →
三个口径 → 空表怎么办**。

必放的三条口径（不写就会被追问）：

1. **只收录「至少被点过 1 次」的提问**。
2. **一行 = 一个提问 × 一个活动 × 一个 ASIN × 一天**。
3. **7 天归因**，且它是 SP 的一个报表维度，不是新的广告类型。

### 第二节 先合并，再算比率

任务：把"直接排序"这个动作彻底否掉。给公式、给小分母的后果、给三个坑
（只记曝过光的、7 天归因、比率列不能取平均）。

### 第三到第七节 五把刀

每把刀固定四段，顺序不许换：

```
取什么数据 → 怎么处理（给公式/步骤）→ 怎么判读（给分档）→ 这把刀在这份表上的答案
```

| 刀 | 这一节的产出 |
|---|---|
| 体检 | 一句话：往下该按层看还是按条看 |
| 集中度 | 有单点黑洞 / 没有单点黑洞（**排除结论也是结论**） |
| 意图分层 | 哪组吃曝光不转化、哪组被饿着、哪组 CTR 最高 |
| 四象限 | 一份名单 + 四格各自的动作 |
| 文本特征 | 哪类说法该写进商品页、哪类该删 |

**写坏的典型**：把第二刀写成"没有结论"。它不是没有结论，它的结论是"这条路不用走"。

### 第八节 补一刀结构

活动 / 时间 / 站点，一屏写完。结论是"分散"就明说后面不必再区分活动。

### 第九节 五把刀走完说了什么

这一节最重要，四件事缺一不可：

1. 最大错配在哪（曝光占比 ÷ 销售占比 最悬殊的那组）。
2. 被饿着的是哪组（销售占比 ÷ 曝光占比 最大、且样本 ≥20）。
3. **极端样本对照表**：几行长尾赚钱 vs 几行流量黑洞。这张表比任何形容词有力。
4. **为什么规则反了** —— 回到机制（搜索框强迫压缩语言，AI 对话框不强迫）。
5. **一个反例**：找一条推翻你自己字面结论的样本（比如一条很短的问句却很赚钱），
   用它把结论从"话越长越值钱"修正成"**这句话里有没有确定性**"。

第 5 条是这篇文章和普通分析的分界线。没有反例，读者会觉得你在套模板。

### 第十节 四个动作

每条写成 **条件 + 动作 + 落点**（五点前三条 / A+ 首屏 / 第二张主图 / 适配表），
末尾加两条执行纪律：改完等 2–3 周；同一批只动一个变量。

### 第十一节 三个边界

单一账户 30 天不是规律 / 只记录曝过光的提问 / 7 天归因。**三条都写，别只写一条。**

### 收尾

把五把刀顺序再压一遍（因为读者最容易记住的是这个）→ 数据声明一行 → 一句轻钩子。

## 数字怎么放（不写数值，写位置）

| 位置 | 放什么 |
|---|---|
| 开篇 | 两条对照提问的曝光/成交 + 全样本八个总量 + 整体 ACOS |
| 体检 | 行数、唯一提问、唯一 ASIN/活动、有销售行占比、基准 ACOS |
| 集中度 | 前 10% / 前 50% 的累计花费与销售、前十活动占比、第一名活动花费 |
| 意图分层 | 六组 × 五个占比 + CTR + ACOS |
| 四象限 | 两条线的值、四格条数、低曝光高效那格的销售占比 |
| 文本特征 | 五类 × 命中数/曝光占比/CTR/ACOS，再加"CTR ÷ 全场"倍数 |
| 极端样本 | 每行：约束数、曝光、CTR、花费、销售、ACOS |

**一个提醒**：这些数全部来自 `out/report.md` 与 `out/prompts.csv`，不要手打、不要记。

## 脱敏怎么写（两层的具体做法）

| 层 | 做法 | 例 |
|---|---|---|
| 品类 | 换成 `〔品类〕` / `[CATEGORY]` | 「〔品类〕的适配宽度」 |
| 属性词 | 材质→`〔材质〕`、功能→`〔功能〕`、结构→`〔结构〕` | 「100%〔功能〕，材质是〔材质〕」 |
| 买家原话 | **只保留结构或约束数** | 「四个约束」/「零约束」 |
| 纯数字 | 保留（不指向品类） | 19 英寸、100%、ACOS 36% |

为什么属性词也要脱：一个材质词加一个功能词，读者自己就能把品类补出来。
而论证本来靠的是**约束数量**，不是哪个词，所以脱掉不损失说服力。

- [ ] 品类与属性词都脱了；没有 ASIN、品牌名、账号
