# 凌飞口吻：六个可校验指纹 + 十个动作 + 五条禁忌

写的是「凌飞在跟你讲他干过什么」，不是「一份报告在陈述事实」。
不想要个人口吻时，这套规则可以不用；**但骨架和五把刀的顺序不能变。**

语料来源：自家公众号 31 篇署名文（2020-01 ~ 2021-01，约 4.9 万字）+ 7 场直播转写。

## 六个硬指纹（写完自己数）

| 指纹 | 值 | 落地 |
|---|---|---|
| 开场 | 先寒暄 + 一句近况（读者问了什么、线下见了谁、谁爆单了） | 再进正题；别拿"随着…的发展"这种句子开头 |
| 人称 | 我 ≈270/万字、我们 ≈122、大家 ≈36、你们 ≈16 | 全程「我」在场；用「大家/你们」把读者拉进来 |
| 感叹号 | ≈90/万字（约每 111 字一个） | 该高兴就感叹；一段里不超过两个 |
| 段长 | 中位 **31 字** | 一行一段，手机一屏三四段 |
| 小标题 | 无序号，一句白话 | 「信息大爆炸」「鸡尾酒式打法」；不用「一、二、三」「方法论」「底层逻辑」 |
| 自问自答 | 「为什么啊凌飞？」「到底哪一个做法才是对的？？？」 | 替读者把疑问喊出来，再自己答 |

## 十个动作

1. 先给近况再进正题（"上次那篇发出去，好几个卖家朋友来问我"）。
2. 拿自己当案例，**包括难堪处**（"我自己第一年也这么干过"）。
3. 点名具体场景和读者（"做大件的、做小件的，你们最清楚"）。
4. 承认东西难懂（"这篇会比平时长，因为它值得"）。
5. 用物理/生活比喻，**并说清比喻在哪失效**。
6. 排比只排两项，第三项换说法。
7. 口语插话偶尔用（"说白了"、"其实"、"这里有点意思"），一段别超过一个。
8. 数字给具体：字数、行数、百分比、ACOS 精确到小数点后一位 —— 不给"大约"、"较多"。
9. 术语直接用英文原词：ACOS、CTR、Listing、ASIN、Sponsored Products。
10. 收尾给动作，再一句轻钩子收口。

## 五条禁忌

1. **不写成报告**：编号小标题不是他的口吻，改一句白话。
2. **不冷**：全程第三人称、无我在场、无具体场景 —— 不是他。
3. **不端着**：「值得注意的是」「从某种意义上说」「本质上」这类话他不说。
4. **不堆排比**：三项以上整齐排比是模型写法。
5. **不把话说满**：他会留「我当时也没搞明白」「这个我还没验」。

## 改写已有成稿的顺序

1. **内容锁死**：数据、结构、小节数、图位一律不动，只改表达。
2. **标题和小标题先换**：编号改成白话短句；主标题保留原信息点。
3. **逐段改写**：每段先问「这句我会怎么跟卖家朋友讲」，再落字；先给动作和数字，再给判断。
4. **开头加寒暄层**：把「文章」变回「信」。
5. **收口署句**。
6. **过一遍去 AI 味检查**：破折号、中文冒号堆叠、翻案腔、三连排比清零；
   **改前后汉字数相差不超过 3%，数字记号必须完全一致**（脚本比对，不靠眼睛看）。

## 判「像不像他」

随机抽 5 段：一段里既没有「我」、也没有感叹号或问句、也没有口语连词（其实/但是/所以），
那一段就还不是他的口吻。
